# G1 · Chạy firmware thật cho board ngoài ATmega328P

Box phụ trách: **02** chốt target, **05** triển khai, **07** kiểm thử, **08** review. Công sức: **L** (3 lát). Cập nhật 05/11/2026 theo quyết định founder **giữ Arduino C++** (`../founder-decisions.md`).

## Mục tiêu

Học viên chọn **Raspberry Pi Pico**, chạy firmware Arduino C++ trên CPU RP2040 giả lập thật trong trình duyệt, quan sát GPIO và UART như với Uno. ESP32 đi đường board thật (G2), không giả lập.

## Hiện trạng trong code

- Chỉ ATmega328P chạy firmware thật: `createAtmega328pMachine` (`src/lib/avr8jsRunner.ts:40`), worker `src/workers/avr8js.worker.ts`, protocol `src/simulation/avr8jsProtocol.ts:4-11`, target Uno/Nano (`src/lib/firmwareTarget.ts:1`).
- Mọi board khác là alias cho interpreter dạy học: `src/data/simulationTargets.ts:3-7`. Pico ở `:38` (GP15), Pico W `:39`, Pico 2 `:40`.
- Hợp đồng provider đã có `'firmware-emulator'` (`src/simulation/contracts.ts:3-7`) và `'firmware-execution' | 'digital-pin-trace' | 'serial-output'` (`:10-16`).
- Firmware Uno mẫu biên dịch sẵn bằng Arduino IDE: `public/firmware/arduino-uno-d13-blink/` (`.hex`, `.ino`); quy trình ghi tại `docs/arduino-toolchain-handoff.md:9`.

## Thiết kế đề xuất

**Lát 1 (S) · Spike headless trong Node.** Biên dịch sketch blink GP15 bằng Arduino core cho RP2040 trên máy box02 (Arduino IDE hoặc arduino-cli cục bộ), lưu UF2 kèm `.ino`, version core và SHA-256. Trong `node --test`, nạp UF2 vào rp2040js, chạy số chu kỳ cố định, ghi transition GP15 và UART.
- rp2040js 1.4.1 export `RP2040`, `Simulator`, `GPIOPin`, `GPIOPinState`, `USBCDC` (`src/index.ts` của repo, nhánh main, đọc 05/11). Bootrom và loader UF2 nằm ở `demo/bootrom.ts` và `demo/load-flash.ts`, **không** export. Box05 đọc hai file này để viết loader; không đoán tên hàm.
- Arduino core cho RP2040: box02 chọn core, ghi version và license [chưa kiểm chứng license].

**Lát 2 (M) · Worker và protocol** song song với AVR, nhận **bytes UF2**:

```ts
// src/simulation/rp2040Protocol.ts (mới)
export type RP2040WorkerRequest =
  | { type: 'start'; runId: string; uf2: ArrayBuffer; targetId: 'raspberry-pi-pico' }
  | { type: 'stop'; runId: string }

export type RP2040Snapshot = {
  target: 'raspberry-pi-pico-rp2040'
  cycles: number
  simulatedMilliseconds: number
  pinTransitionEvents: Array<{ pin: number; level: boolean; simulatedMilliseconds: number }>
  traceTruncated: boolean
  serialText: string
  serialTruncated: boolean
}

export type RP2040WorkerResponse =
  | { type: 'frame' | 'complete'; runId: string; frame: RP2040Snapshot }
  | { type: 'stopped'; runId: string }
  | { type: 'error'; runId: string; message: string }
```

Giữ cơ chế `runId` và chạy theo chunk bằng `setTimeout` như `avr8js.worker.ts:24-44`; giới hạn transition/serial như `avr8jsRunner.ts:22-23`.

**Lát 3 (M) · UI.** Tab Pico trong `FirmwareHexToolPage` (hoặc trang mới): chọn UF2 mẫu hoặc tệp UF2 người dùng, chạy/dừng, trace GP15 và serial. Khi compile service (G2) có, thêm nút "Biên dịch và chạy" gửi sketch lên service rồi nạp UF2 trả về. Chỉ bật cho `raspberry-pi-pico`; Pico W và Pico 2 giữ nhãn interpreter.

## Test cần viết

`node --test tests/uf2.test.mjs tests/rp2040-runner.test.mjs`:
1. `uf2.ts` từ chối block sai magic hoặc family ID khác RP2040, báo lỗi tiếng Việt.
2. UF2 mẫu blink tạo đúng chuỗi transition GP15 HIGH/LOW xen kẽ, thời gian mô phỏng tăng dần, khoảng cách khớp `delay()` trong `.ino` với sai số đã ghi.
3. Sketch mẫu `Serial.println("mach-mo-ok")` cho serial chứa `mach-mo-ok` [cần box02 xác nhận UART/USB CDC mà core dùng cho `Serial`; rp2040js có `USBCDC`].
4. Chạy tới `maxCycles` trả `complete`, không treo test.
5. Lệnh `stop` giữa chừng trả `stopped`, không xuất được như lượt hoàn tất (cùng quy tắc W2).

## Rủi ro

- **Gate phân phối:** UF2 mẫu và bootrom là binary phân phối lại, **chịu cùng loại gate như G5**.
- Arduino core RP2040 có thể dùng USB CDC cho `Serial`; rp2040js hỗ trợ USB CDC nhưng cần kiểm trên đúng core.
- Tốc độ emulator JS với firmware Arduino (có USB stack) [chưa đo].
- Không có compile service thì học viên chỉ chạy được UF2 mẫu hoặc UF2 tự biên dịch.
