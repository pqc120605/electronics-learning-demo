## Thiết kế đề xuất

- Thêm query `variant` (ví dụ `?component=resistor&variant=resistor-10000ohm`). Thiếu `variant` thì giữ trang họ điện trở như hiện tại. `variant` lạ hiển thị "Không tìm thấy biến thể" và vẫn giữ trang họ.
- Điều khiển: `<fieldset>` + `<legend>` + hai `<input type="radio">` có nhãn "220 Ω", "10 kΩ". Đổi lựa chọn thì cập nhật query bằng `setSearchParams` (đã dùng ở `ComponentsPage.tsx:47`), giữ nguyên các query khác.
- Mỗi biến thể hiển thị: trị số danh định, `bomKey`, `spiceLiteral`, nguồn (bài LED hoặc preset `analog-ldr`) và dòng "Dung sai, công suất, package: chưa xác định".
- Giữ geometry `reference-only` tách khỏi khả năng mô phỏng (`resistor-variant-handoff.md:11-12`).

Hàm thuần đề xuất, đặt trong `src/lib/componentCatalog.ts` để test bằng Node:
