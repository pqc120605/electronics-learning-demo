# W2 · Capture firmware Uno R3 / CSV có digest HEX, target, pin, thời gian mô phỏng

Box phụ trách: **05** triển khai, **01** chốt định nghĩa digest (đã có trong dispatch), **07** kiểm thử, **08** review. Công sức: **S–M**. Tách từ MM-RUN-001.

## Mục tiêu

Mỗi CSV xuất ra gắn được với đúng tệp HEX đã chạy, đúng target đã xác nhận, đúng engine và timebase. Lượt bị dừng hoặc lỗi không được xuất như lượt hoàn tất.

## Hiện trạng trong code

- CSV hiện có 7 cột `source,target,signal,simulated_ms,cycles,level,trace_truncated`: `firmwareTraceCsv` tại `src/lib/firmwareWorkflow.ts:35-41`; tải xuống tại `:43-50`.
- Snapshot `Atmega328pSnapshot` (`src/lib/avr8jsRunner.ts:25-37`) không mang digest, target confirmation hay trạng thái lượt chạy.
- Timebase: `simulatedMilliseconds = cpu.cycles / (target.clockHz / 1000)` (`avr8jsRunner.ts:84`, `:103`). Giới hạn chạy 1 s mô phỏng (`maxCycles: target.clockHz`, `:118`).
- Trang `src/pages/FirmwareHexToolPage.tsx`: đổi tệp hoặc target thì xóa frame (`:50-51`, `:245-246`), tốt. **Lỗi:** khi worker trả `stopped` (`:150`), frame cuối vẫn được giữ và nút tải CSV hiện ở `:214` với điều kiện `!avrRunning && pinTransitionEvents.length > 0`. Một lượt người dùng bấm dừng vẫn xuất CSV giống lượt hoàn tất.
- Worker gửi `complete` khi đủ `maxCycles` (`src/workers/avr8js.worker.ts:28-30`).
- Engine: `avr8js` 0.21.1 vendored (`package.json`, `vendor/avr8js-0.21.1.tgz`).

## Thiết kế đề xuất

Tách metadata lượt chạy khỏi snapshot, không đổi `Atmega328pSnapshot`:

```ts
// src/lib/firmwareWorkflow.ts
export type FirmwareRunRecord = {
  hexSha256: string              // SHA-256 hex chữ thường của bytes UTF-8 của chuỗi HEX đã gửi worker
  hexByteLength: number
  targetId: Atmega328pBoardId
  targetConfirmed: true
  engine: 'avr8js'
  engineVersion: string          // hằng số, cập nhật cùng package.json
  clockHz: number
  status: 'complete' | 'stopped' | 'error'
}

export async function sha256Hex(text: string): Promise<string> // dùng globalThis.crypto.subtle
export function firmwareTraceCsv(frame: Atmega328pSnapshot, run: FirmwareRunRecord): string
```

- Định nghĩa digest: hash **bytes UTF-8 của đúng chuỗi `hexSource` gửi vào `worker.postMessage`** (`FirmwareHexToolPage.tsx:167`), không chuẩn hóa xuống dòng. Ghi định nghĩa này trong docstring. Nếu box01 đã chốt định nghĩa khác, theo box01.
- CSV: giữ nguyên 7 cột đầu và thứ tự; **nối thêm** cột `hex_sha256,engine,engine_version,clock_hz,run_status`. Người dùng file cũ đọc theo tên cột vẫn chạy.
- Chỉ cho xuất khi `status === 'complete'`. Lượt `stopped` hiển thị "Lượt chạy đã dừng, chưa xuất được dữ liệu" và ẩn nút tải.
- Tính digest khi bấm chạy (trước `postMessage`), lưu vào state cùng `runId`; bỏ record khi đổi tệp/target (cùng chỗ đang `setAvrFrame(undefined)`).
