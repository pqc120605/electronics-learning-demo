# G3 · IoT (MQTT)

Box phụ trách: **04** học liệu, **01** kiến trúc, **05** triển khai, **08** review an toàn dữ liệu. Công sức: lát 1 **M**, lát 2 **L**. Phụ thuộc: lát 2 cần G2 (board thật có mạng).

## Mục tiêu

Người học hiểu và thử được mô hình publish/subscribe: thiết bị gửi số đo lên topic, dashboard nhận và vẽ, dashboard gửi lệnh bật LED.

## Hiện trạng trong code

- Không có MQTT: `grep -rli mqtt src` trả 0 file.
- Emulator hiện có (AVR8js) và emulator đề xuất (rp2040js, G1) **không có mạng**. Pico gốc không có Wi‑Fi; Pico W có chip CYW43 mà rp2040js không giả lập [README rp2040js không nêu CYW43; chưa kiểm chứng thêm].
- Hợp đồng provider: `src/simulation/contracts.ts:3-16` chưa có capability mạng.

## Thiết kế đề xuất

**Lát 1 (M) · MQTT ảo trong trình duyệt, không server, không package.**
- Một broker giả lập trong bộ nhớ trang (khoảng 100 dòng), đúng ngữ nghĩa topic, wildcard `+`/`#`, retained, QoS 0. Không cần `mqtt` npm vì không có kết nối mạng thật.
- Thiết bị ảo phát dữ liệu (ví dụ nhiệt độ từ biến trở trong mạch SPICE hoặc từ GPIO của AVR8js/rp2040js) lên topic; panel dashboard subscribe và vẽ.
- Hiển thị rõ nhãn "Mô phỏng, không gửi dữ liệu ra Internet".

```ts
// src/lib/virtualMqtt.ts (mới)
export type MqttMessage = { topic: string; payload: string; retained: boolean; at: number }
export function topicMatches(filter: string, topic: string): boolean   // theo MQTT 3.1.1 §4.7
export function createVirtualBroker(): {
  publish(topic: string, payload: string, opts?: { retain?: boolean }): void
  subscribe(filter: string, onMessage: (m: MqttMessage) => void): () => void
}
```

**Lát 2 (L) · Board thật qua broker thật.** Chỉ làm sau G2. Trình duyệt dùng `mqtt` 5.16.1 (MIT) qua WebSocket TLS tới broker do Mạch Mở hoặc nhà trường vận hành. Cần quyết định hosting, xác thực theo lớp, giới hạn tốc độ và thời gian lưu. Không dùng broker công cộng cho học sinh.

## Test cần viết (`node --test tests/virtual-mqtt.test.mjs`)

1. `topicMatches`: `a/+/c` khớp `a/b/c`, không khớp `a/b/d`; `a/#` khớp `a`, `a/b`, `a/b/c`; `#` không khớp topic bắt đầu bằng `$` (MQTT 3.1.1 §4.7.2).
2. Retained: subscribe sau publish retain vẫn nhận tin cuối.
3. Hủy subscribe thì không nhận tin mới.
4. Payload dài hơn giới hạn đặt ra (ví dụ 1 KB) bị từ chối với lỗi tiếng Việt.
