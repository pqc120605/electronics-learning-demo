# G4 · Lập trình khối

Box phụ trách: **06** thiết kế, **04** học liệu, **05** triển khai, **07**, **08**. Công sức: **M**.

## Mục tiêu

Người mới (học sinh nhỏ) kéo khối để viết chương trình cho bài LED/nút/LED 7 đoạn hiện có, xem được code tương ứng, chạy bằng đúng đường mô phỏng hiện tại.

## Hiện trạng trong code

- Không có Blockly: `grep -rli blockly src` trả 0 file.
- Đường chạy code hiện tại: code text → `parseSupportedArduinoSubset` (`src/lib/parseSupportedArduinoSubset.ts:9`, trả `ParseResult` tại `:3`) → IR (`src/lib/lessonProgramIr.ts`) → interpreter (`src/lib/educationalSimulator.ts`, `EduProgram` tại `:7`).
- Xuất `.ino` dùng cùng code text (`src/lib/arduinoSketchExport.ts:49`).

## Thiết kế đề xuất

Blockly **sinh code text trong tập con Arduino đã hỗ trợ**, không tạo đường mô phỏng thứ hai. Mọi thứ phía sau (parser, IR, interpreter, xuất `.ino`) giữ nguyên.

- Bộ khối tối thiểu khớp tập con parser: `setup`/`loop`, `pinMode`, `digitalWrite`, `digitalRead`, `delay`, `if`, biến số nguyên. Box05 lập bảng khối ↔ cú pháp parser bằng cách đọc `parseSupportedArduinoSubset.ts`; khối nào parser không nhận thì không đưa vào.
- Generator tùy biến (Blockly có API generator cho ngôn ngữ riêng). Kết quả generator luôn qua `parseSupportedArduinoSubset`; parse lỗi là bug của generator.
- Lưu workspace khối dạng JSON trong project bundle như một trường tùy chọn [cần box01 xác định vị trí trong `src/lib/projectBundle.ts:10` mà không đổi `PROJECT_BUNDLE_VERSION` (`:2`) hoặc có migration].
- Lazy-load: chỉ tải Blockly khi người dùng mở chế độ khối. Build hiện đã tách chunk theo route (`dist/assets` có chunk `CircuitBuilderPage-*.js` 180,8 KB).
- Founder giữ Arduino C++ (05/11): chỉ làm generator tập con Arduino; không làm generator Python.

