# MoBot V2 · Quyết định Founder về chuyển chế độ tay cầm

Founder chọn đổi sang **RUN → OFF → PROGRAM** trong chat HQ, sau khi đối chiếu hai phương án do Box 01 và 03 bàn giao. Quyết định thay phần thao tác rút trực tiếp cáp RUN của Q2-A. Một cổng USB-C trên B01 vẫn dùng luân phiên cho RUN hoặc PC. Cổng CHARGE riêng, Jauch/H3 và D10 giữ nguyên.

- Khi yêu cầu OFF, giữ phích RUN trong lúc khóa I/O, thu hồi RUN và xả RUN OUT. Chỉ cho nhả khi đã xác nhận I/O thực sự cách ly, Source thực sự tắt và RUN OUT dưới ngưỡng đã review.
- Mất bias hoặc trạng thái chưa xác nhận không được cho phép nhả phích. Cách tháo bảo trì khi hết pin phải duy trì điều kiện cách ly nguồn.
- Cần bằng chứng trên đúng cụm về giữ/nhả, lỗi một điểm, cắm rút lệch, thao tác đi vòng và timing qua CHARGE, brownout, lỗi sense. Hai ca chức năng C-to-C vẫn theo dõi riêng và chưa chạy.

Đây là chấp thuận hướng thiết kế. Hash mới cần Box 08 review và Founder duyệt riêng. Các gate kỹ thuật và quyền vận hành vẫn áp dụng.
