# Local beginner learning

The founder approved the competitive improvement proposal and requested local implementation while server work waits. This delivery completes a self-contained beginner course and its local return journey. Reuse the current circuit document, breadboard topology and educational interpreter.

## Learner flow

Public home and app home offer a first lesson, existing practice and the empty freestyle bench. The beginner lesson opens at /learn/basics and /app/learn/basics, before generic lesson routes. Existing lesson URLs continue to work.

Five activities teach closed return paths, breadboard strips, LED polarity and the series resistor, INPUT_PULLUP button logic, and a sensor threshold. Every activity contains prediction, an explicit observation action and an explanation choice. Hints grow from locating the relevant part to explaining its role. Learners can visit any activity and repeat it.

The first three activities use an idealized conceptual circuit and the existing breadboard electrical model. The button and threshold activities require an explicit supported board choice. Generate the code for that board and execute the existing educational parser. Show its input, comparison and output beside the circuit. A result belongs to the input and code that produced it. Editing controls removes the current displayed result until the learner runs again.

Completion means the required predictions were checked against matching model observations and the explanation choice is correct. Free-text explanations are outside this delivery. Existing self-reported completion remains separately labeled. The course records no personal identity or remote analytics.
